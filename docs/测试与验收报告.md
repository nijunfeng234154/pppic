## 已覆盖的关键验收点

1. 静态页面、OpenAPI 和健康接口可读取，管理接口未认证返回 401。
2. 登录失败、cookie 属性、跨源写入拒绝、注销后会话失效；暴力尝试触发限流。
3. 上传 → 实际文件落盘 → 图片信息 → 公开字节读取 → ETag → 编辑 → 搜索/相册/收藏筛选 → 删除 → 公开链接 404。
4. 并发上传相同文件只创建一条记录；通配符及 SQL 片段作为普通搜索文本处理。
5. 非图片、SVG、截断头、超限文件、无 Content-Length 超限请求、畸形表单、重复 file、错误 JSON 和非法分页被拒绝。
6. upload/read/manage 权限边界、密钥哈希保存、列表不泄露原文、撤销立即失效、最近使用时间更新。
7. 用户文件名与实际路径分离，分享文本过滤属性注入字符，路径穿越无法读取本地文件。
8. 配额生效、重复上传不额外计费；存储写入失败不创建记录、删除失败保留记录；数据库可重开并读到已有记录。

## 代码复查及修复

按上游 code-quality 和 api-testing 清单人工复查，已修正：原图读取改为流式传输；超限请求停止缓冲并返回结构化错误；本地写入使用临时文件后同目录原子替换；相册切换清除不相关搜索条件；数据库拒绝高版本 schema；401 返回认证挑战头；OpenAPI 明确声明 created 字段。

未执行第三方渗透测试、压力测试或完整 OpenAPI schema 验证器。图片检查仍为文件头识别，未覆盖所有格式畸形变体，也不等于内容安全扫描。
