# pppic：受限环境图床交付

- 背景：空目录开发单租户 Web + API 图床，默认本地存储，支持 S3 兼容适配。
- 方法：产品验收先行，复用 e2e-feature-delivery；SQLite 元数据、分权限密钥、存储驱动隔离。
- 已验证：16 项单元/请求注入集成测试通过，含五种真实图片、权限矩阵、并发去重、失败恢复与配额。
- 环境边界：本机端口监听 EPERM，Chrome 无头启动失败；真实 HTTP/浏览器/Docker/云桶未验收。
- 可复用经验：无法开端口时，将标准 Request 序列化后注入同一 handler；保留真实 HTTP 模式和浏览器用例，报告必须区分验证层次。文件写入使用临时文件加原子替换，单实例内串行化去重与配额。
- 详细交付：[项目经验](../../../../docs/交付经验.md)、[验收报告](../../../../docs/测试与验收报告.md)。
